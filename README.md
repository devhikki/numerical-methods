# ОП.10 Численные методы — практические работы 2–4, вариант 9

Работы оформлены в Jupyter Notebook (`.ipynb`). В каждом ноутбуке приведены исходные данные, формулы, код, результаты расчётов и выводы.

## Состав

- [ПР № 2 — Нелинейные уравнения](ПР_2_Нелинейные_уравнения.ipynb): отделение корней, бисекция, простая итерация, хорды и касательные, проверка SciPy.
- [ПР № 3 — Системы линейных уравнений](ПР_3_Системы_линейных_уравнений.ipynb): метод Гаусса, простая итерация для СЛАУ, проверка NumPy.
- [ПР № 4 — Интерполяция и экстраполяция](ПР_4_Интерполяция_и_экстраполяция.ipynb): Лагранж, кубический сплайн, формулы Ньютона.

Каждый ноутбук самодостаточен: его можно открыть отдельно и выполнить ячейки сверху вниз. Исходные данные, расчёты, таблицы и графики находятся внутри ноутбуков.

## Запуск

1. Скачать репозиторий и распаковать его в отдельную папку.
2. Из этой папки установить зависимости: `python3 -m pip install -r requirements.txt`.
3. Запустить Jupyter: `python3 -m notebook` (либо открыть файлы в VS Code с расширением Jupyter).
4. Открыть практические работы в порядке № 2, № 3, № 4. В каждой выбрать ядро **Python 3** и выполнить **Run All**.

Внешние `.py` не требуются. При повторном запуске ПР № 2 и № 4 сохраняют графики в PNG.

Можно просто просмотреть уже сохранённые результаты на GitHub, даже без выполнения кода.

## Примечание к ПР № 4
