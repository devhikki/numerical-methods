# ОП.10 «Численные методы» — ПР № 2–4, вариант 9

- [ПР № 2](pr2_equations) — решение нелинейных уравнений.
- [ПР № 3](pr3_linear_systems) — решение систем линейных уравнений.
- [ПР № 4](pr4_interpolation) — интерполяция и экстраполяция.

## Запуск

В корне проекта выполните:

```bash
python3 -m pip install -r requirements.txt
python3 demo.py
```

`demo.py` запускает 13 программ, проверяет ключевые численные результаты и сохраняет протоколы в `results/`.

Чтобы запустить отдельную программу, перейдите в её каталог. Например, для метода половинного деления:

```bash
cd pr2_equations
python3 task2_bisection.py
```
